# Earth background texture

`earth_blue_marble_topo_bathy_21600.jpg` is NASA Earth Observatory's January
2004 Blue Marble: Next Generation base map with topography and bathymetry
(21,600 × 10,800 pixels, 2 km per pixel). This version includes shaded ocean
floor relief. NASA asks users to credit “NASA Earth Observatory.” It is used for
both the flat map and globe:

<https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-topography-bathymetry/>

`earth_blue_marble_topo_bathy_4096.bmp` is a 4096 × 2048, 24-bit upload copy
derived from the NASA image. The full-resolution JPEG is retained as the source.

`earth_natural_earth_2_relief_water_4096.bmp` is a 4096 × 2048 rendering of
Natural Earth II with shaded relief, water, and drainages, 1:10m raster. Natural
Earth data is free for use in any type of project. The source download is hosted
by Natural Earth/NACIS:

<https://www.naturalearthdata.com/downloads/10m-raster-data/10m-natural-earth-2/>

The cartographic Natural Earth texture is the default for the flat map and
globe; NASA Blue Marble remains available as an alternate background.
