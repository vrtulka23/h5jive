# GOME-2 Band 3 sample

`gome2_band3_20130106_gome.nc` contains a modified extract of a Metop-B
GOME-2 Level 1B product observed on 6 January 2013, orbit 32260. The source
product recorded in the file is `20130106101404Z_32260_gome.nc`. The sample
keeps all 625 scan lines and 32 ground pixels, along with Band 3 geolocation,
pixel bounds, scan direction, and 64 consecutive radiance channels starting at
source channel 480. It is a spectral subset, not a spatially downsampled copy
or the complete source product.
