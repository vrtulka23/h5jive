# Examples

Examples are grouped by their purpose:

| Directory | Contents |
| --- | --- |
| [`arrays/`](arrays/) | General HDF5 arrays for inspector and visualization demos |
| [`satellite/`](satellite/README.md) | GOME-2 NetCDF sample with a [data licence](satellite/LICENSE.md) |
| [`plugins/path_comparison/`](plugins/path_comparison/) | A/B structure and metadata comparison demo |
| [`plugins/value_comparison/`](plugins/value_comparison/) | Numeric arrays with known differences and ratios |
| [`plugins/dataset_manipulation/`](plugins/dataset_manipulation/) | Reproducible slices and arithmetic operations |
| [`plugins/spatiotemporal_subset/`](plugins/spatiotemporal_subset/README.md) | Synthetic North Sea swaths and a [real ERA5 sample](plugins/spatiotemporal_subset/era5/LICENSE.md) for NetCDF subsetting |

Each plugin directory has its own README and generator command.
