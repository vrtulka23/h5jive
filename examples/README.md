# Examples

Examples are grouped by their purpose:

| Directory | Contents |
| --- | --- |
| [`arrays/`](arrays/) | General HDF5 arrays for inspector and visualization demos |
| [`satellite/`](satellite/) | GOME-2 NetCDF sample for geospatial views |
| [`plugins/path_comparison/`](plugins/path_comparison/) | A/B structure and metadata comparison demo |
| [`plugins/value_comparison/`](plugins/value_comparison/) | Numeric arrays with known differences and ratios |

Each plugin directory has its own README and generator command.
