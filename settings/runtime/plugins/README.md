# Plugin settings

These files provide concrete settings for Plugin Lab tools. Their types and
defaults are defined by [plugin schemas](../schemas/plugins/README.md).
[`plugins.dip`](../plugins.dip) holds the central enable switches, while
[`viewer.dip`](../viewer.dip) includes each plugin source in the application
tree. The [runtime DIPfile](../DIPfile) registers every source.
